# DVCOE Canteen Ordering System

A modern, responsive, and multilingual canteen ordering system built for Dnyanvilas College of Engineering.  
This project allows users to browse menu items, add food to cart, place orders, track current orders, view order history, switch themes, and change language.

## Features

- Modern glassmorphism UI
- Responsive design for desktop and mobile
- Food menu with images, prices, and availability status
- Add to cart functionality
- Quantity increase/decrease controls
- Order confirmation modal
- Current orders section
- Order status flow:
  - Pending
  - Preparing
  - Ready
  - Completed
- Order history section
- Dark and light theme toggle
- Multilingual support:
  - English
  - Hindi
  - Marathi
  - Japanese
- Search menu feature
- Toast notifications
- Premium footer with social links

## Tech Stack

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Responsive CSS Grid/Flexbox
